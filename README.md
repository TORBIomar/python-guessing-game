## 🎮 How to Play

1. The computer chooses a secret random integer between **1 and 100**.
2. Enter your best guess in the prompt.
3. Receive instant directional guidance:
   - 📈 *Too High! Try a smaller number.*
   - 📉 *Too Low! Try a larger number.*
4. Narrow down the target using optimal binary search strategy and guess in the fewest attempts possible!

---

## 🚀 Quick Run

```bash
# Clone the repository
git clone https://github.com/TORBIomar/python-guessing-game.git
cd python-guessing-game

# Run the game
python guessing_game.py
```
